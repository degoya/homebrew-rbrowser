# rBrowser for Homebrew

The Homebrew tap of [rBrowser](https://github.com/degoya/rBrowser), a development browser that
shows every breakpoint of a site at once: a cask for macOS (Apple Silicon and Intel) and a formula
for Linux (x86-64).

```bash
# macOS
brew install --cask degoya/rbrowser/rbrowser
# Linux
brew install degoya/rbrowser/rbrowser
```

`brew upgrade rbrowser` brings the next release; rBrowser installed through Homebrew does not
replace itself. The macOS app is signed ad hoc, not notarised: macOS asks once before its first
start.

Current version: 0.9.8. The cask and the formula are written by the release workflow of
[degoya/rBrowser](https://github.com/degoya/rBrowser) with every release - issues and changes go there,
not here. The handbook's installation page:
<https://github.com/degoya/rBrowser/wiki/installation>.
